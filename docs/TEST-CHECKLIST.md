# 真机测试清单（发布/活动前人工过一遍）

自动化冒烟测试（`tests/`）只覆盖逻辑层；麦克风权限、系统音量、回授这些只有真机能验证。
**活动前至少完成 A 组；有手机玩家则补 B 组。**

## A. 演示机（Mac/Windows + Chrome/Edge，大屏）

| # | 项目 | 步骤 | 通过标准 |
|---|---|---|---|
| A1 | 麦克风权限 | 全新隐身窗口打开页面 → 开麦 | 权限弹窗出现；允许后无报错 |
| A2 | 已授权免弹窗 | 正常窗口二次打开 → 开麦 | 不再弹窗，直接进校准 |
| A3 | 噪音校准 | 安静 2 秒 | 提示按流程推进，无跳变 |
| A4 | 试喊校准 | 按提示大喊一嗓子 | 提示"起跳线已按你的嗓门校准" |
| A5 | 起跳手感 | 玩一局，小喊/大喊各一次 | 小喊能过低障碍；大喊明显更高更远 |
| A6 | 灵敏度滑杆 | 灵敏度调到 0.6 和 1.8 各试一次 | 阈值明显变难/变易 |
| A7 | 音箱回授 | 大屏外放、音量 70%，玩一局 | 音乐/音效不误触发跳跃（回声消除生效） |
| A8 | 全屏 | 按 F | 全屏正常、画面等比不裁切、HUD 完整 |
| A9 | 断网兜底 | 断网刷新页面（已装 PWA 的设备） | 仍可完整游玩（Service Worker 缓存） |
| A10 | 单文件版 | 双击 `dist/malou-offline.html` | file:// 下完整可玩（含空格/触摸，麦克风不可用属正常） |

## B. 手机（微信外的浏览器）

| # | 项目 | 平台 | 通过标准 |
|---|---|---|---|
| B1 | 布局 | Android Chrome + iOS Safari | 横屏后画面完整等比；竖屏提示旋转或自动旋转 |
| B2 | 麦克风 | Android Chrome | HTTPS（Pages 链接）下可授权、可起跳 |
| B3 | 麦克风 | iOS Safari | 权限弹窗出现且可允许；试喊校准正常 |
| B4 | 触摸蓄力 | 任意 | 长按屏幕出现蓄力弧，松手起跳；快按=小跳 |
| B5 | 横竖屏切换 | 任意 | 切换后不白屏、不卡死 |
| B6 | 安装到主屏 | iOS Safari 分享→添加到主屏 | 打开即全屏（无浏览器栏），可离线 |

## C. 已知限制（不是 bug，别当故障修）

- iOS 锁定静音键时部分版本网页音频无声 → 游戏开始前提示玩家关静音。
- 微信内置浏览器不保证支持 getUserMedia → 引导用系统浏览器打开。
- file:// 单文件版没有麦克风（浏览器限制），空格/触摸可玩。
