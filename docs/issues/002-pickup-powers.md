- 依赖：#001（阶段 / 套路段）已合入

## 背景

当前 ☕ / 🧋 只加分，玩家没理由冒险去拿；持续喊叫嗓子容易累，缺少「喘息」机制。

## 目标

| 道具 | 原有效果 | 新增效果 |
| --- | --- | --- |
| ☕ 咖啡 | +20 行 | 回充发疯值 +25（可叠到 100，仍受闭嘴区冻结影响：拿到时直接加，不依赖喊） |
| 🧋 奶茶 | +50 行 | 获得 **1 层护盾**（已有护盾时再拿只加分，层数封顶 1） |
| 🍌 香蕉 | （新）+15 行 | 累计收集，集满 3 根触发 **摸鱼时间** 4 秒 |

### 护盾规则

- 挡一次本会致死的碰撞：**地面障碍、深坑坠落、纸飞机**都挡（「这个先挂 TODO」）。
- 触发时：护盾清零、障碍若为地面障碍则销毁（不计捶爆分）、深坑则把吗喽弹回地面、纸飞机标记 dead；屏幕闪一下 + 浮动文字「🛡️ TODO 挡住了!」。
- 狂暴捶爆优先于护盾：狂暴中撞地面障碍仍走捶爆，不消耗护盾。
- HUD 在发疯值旁显示 `🛡️×1`。

### 摸鱼时间（集 3 🍌）

- 持续 4 秒：自动按演示 AI 同款逻辑起跳（纸飞机仍闭嘴、不开麦也能过）；玩家手动喊声仍可覆盖。
- 期间脸变成 😴，头顶「摸鱼中…」；结束后香蕉计数清零重新攒。
- 香蕉高度约 420–450（中空，中等力度跳可得）；生成概率约咖啡的一半，站会及之后才出现。

## 验收标准

- 现有冒烟全部通过。
- 拿咖啡：bonus +20 且 madness 增加 25（封顶 100）。
- 拿奶茶后撞地面障碍：不死、护盾清零、障碍消失。
- 无护盾撞障碍：仍死。
- 狂暴中撞地面障碍：走捶爆、护盾不被消耗（若有护盾）。
- 集 3 香蕉触发摸鱼；摸鱼期间无输入可通过一段「连环 Bug」。
- 结算可看到护盾挡次数 / 摸鱼次数（有则显示）。
- 全程无 JS 错误。
