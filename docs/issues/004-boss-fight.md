# Issue #004：终点 Boss 战（产品经理）

- 状态：✅ 已完成（冒烟测试 45/45）

### 实现备注
- Boss 本体是**软门**（挡住不秒杀），真正威胁是它扔的纸飞机/Bug；发疯撞破 +100，超时 8 秒撤兵也可冲线。
- 登场时清空镜头前旧障碍，避免宽坑卡在门前。
- 软门让吗喽停在 Boss 前 300px（`BOSS.GAP`）；发疯时不挡，可一路冲上去撞破。出场位置按镜头算（`BOSS.AHEAD`），短赛程也在前方且软门落在终点前。
- 攻击（每 1.5–1.9 秒）：45% 扔 Bug，从 Boss 脚下以 220px/s 爬向吗喽（跳过或发疯撞碎）；否则从手里甩出 240px/s 的快飞机。Bug 爬到脚下时若纸飞机正压头顶则改扔飞机，避免必死组合。
- 发疯冲锋期间 Boss 停手；捶爆或撤兵时清空前方所有扔出物，直接冲线。
- 闭嘴区只算前方还没飞过头顶的纸飞机（全局规则），否则 Boss 段发疯值 79% 时间被冻结。
- 分支：`feature/new-play-mechanics`
- 依赖：#002、#003
- 涉及文件：`js/config.js`、`js/world.js`、`js/game.js`、`js/render.js`、`js/sfx.js`、`js/ui.js`、`tests/smoke.spec.mjs`、`README.md`

## 背景

92% 冲刺段目前只是加速 + 阶段横幅，缺少高潮。年会暖场最需要「最后一搏」的记忆点。

## 目标

进入 **🚀 02:00 凌晨上线**（进度 ≥ 92%）时触发 Boss 战，替代该段的普通障碍生成：

1. **登场**：屏幕右侧出现 Boss「👔 产品经理」（世界坐标钉在镜头右侧），横幅「👔 产品经理来了：需求还会再变!」。
2. **攻击**：每 1.5–1.9 秒扔一架纸飞机（仍走闭嘴区规则）或一颗爬向吗喽的地面 Bug。
3. **破防**：玩家进入发疯写码并撞上 Boss（或累计捶爆其扔出的 3 个地面障碍）→ Boss 被捶爆，+100 行，进入净土冲线。
4. **超时兜底**：若 Boss 战超过约 8 秒仍未破防，自动收兵进入净土（避免卡死），不计捶爆奖。
5. **通关**：破防或收兵后 `spawnX` 推到终点外，跑过 🏁 照常胜利；结算显示「👊 捶爆了产品经理」或「勉强上线（Boss 撤了）」。

### 与现有系统的关系

- 纸飞机仍致命；护盾（#002）可挡一次；滑翔（#003）对 Boss 段无特殊加成。
- 演示 AI：Boss 段优先闭嘴躲飞机，见地面 Bug 再跳；尽量在段内攒发疯值捶 Boss（可通过缩短 Boss 血量/提高充电在测试里验证）。
- 原冲刺加速 `SPRINT_BONUS` 保留。
