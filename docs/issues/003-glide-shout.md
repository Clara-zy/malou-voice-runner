## 背景

声音目前只用了「响度→跳高」和「时长→发疯值充电」。空中无法再操作，宽坑只能靠起跳力度赌距离。「喊多久」缺少在跳跃过程中的操作意义。

## 目标

- **空中持续喊**（音量 ≥ 起跳线）：下落重力降为约 45%（滑翔），松开或音量掉下起跳线立即恢复正常重力。
- 只在空中生效；地面喊声行为不变（起跳 + 发疯值充电照旧）。
- 滑翔时吗喽身后拉出淡淡音浪线；浮动提示首次触发「🎙️ 滑翔中」。
- 演示 AI：遇到宽坑（`w ≥ 140`）时，起跳后在空中保持喊声直到越过坑沿。
- 新增套路段「宽坑滑翔」（深夜加班解锁）：一个 160–180px 宽坑，小跳过不去，满力跳 + 滑翔可过；反例测试：满力跳但不滑翔会掉坑。

### 参数（`GLIDE`）

```
GRAVITY_MUL: 0.45   // 滑翔时重力倍率
MIN_AIR: 20         // 离地至少这么多才算滑翔（避免贴地蹭）
```

空格/触摸蓄力松手后的喊声包络 `shoutT` 也会维持滑翔（与麦克风取较大值），方便无麦调试。

## 实施步骤

1. 滑翔物理 + 视觉/音效 + 演示 AI 宽坑策略
2. 宽坑滑翔套路段 + 测试（可过 / 不滑翔掉坑）+ README

## 验收标准

- 现有冒烟全部通过。
- 空中持续满力喊：滞空时间明显长于同力度静音下落（断言最大滞空帧数或落地距离）。
- 宽坑套路：演示 AI（含滑翔）20/20 通过；强制不起滑翔 10/10 掉坑。
- 地面持续喊不会「浮空」。
- 全程无 JS 错误。
