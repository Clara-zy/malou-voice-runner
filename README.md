# 🐵 吗喽声控跑酷 —— 别让吗喽掉进 Bug

一个给团队活动 / 年会暖场用的**声控跑酷小游戏**：吗喽自动匀速往前跑，你只负责一件事——**喊**。
看到障碍大喊一声让它跳过去，喊得越响跳得越高越远；躲开 NullPointerException、404、P0 故障、
需求变更（纸飞机）和技术债深坑，跑满 1000 行代码即可「成功上线」。

纯前端：Canvas + Web Audio，**零依赖、无后端、无构建**，克隆下来一个静态服务就能跑。

## 玩法

| 情况 | 操作 / 结果 |
| --- | --- |
| 开局 | 吗喽自动匀速往前跑，玩家不需要管移动 |
| 🐛🚧💣 地面障碍（NPE / 404 / P0） | **大喊起跳**：声音超过门槛就起跳，**喊得越响跳得越高越远** |
| ✈️ 纸飞机（需求变更）从头顶飞过 | **闭嘴！** 在它下面起跳必死 |
| 🕳️ 技术债深坑 | 坑越宽越要喊得响，起跳别太早 |
| 跑满 1000 行代码 | 🎉 上线成功，上排行榜 |

- `F` 全屏（投大屏用） · `M` 音效开关
- 开局流程：点「🎤 开麦上班」→ 保持安静 2 秒校准环境噪音 → 对着音量条试一嗓子（冲进红区就会起跳）→ 3-2-1 自动开局
- 死亡后输入花名上排行榜（本机 localStorage，前 10 名；死亡界面附赠一条对应的复活小技巧）

### ⌨️ 开发调试：空格模拟喊声

没有麦克风或想精确复现音量时可用：**按住空格蓄力（按得越久模拟的嗓门越大），松开才喊出来**。
轻点≈小跳（~190px），按满 0.38s≈满力大跳（~224px）。`↑` 等效一次满力度喊声。
开始界面点「⌨️ 空格调试模式（不开麦）」即可；开麦状态下空格同样可用，两者取最大值。

自动演示：`http://localhost:8080/?demo`（内置 AI 自动玩，可做投屏暖场 attract mode）；
`?goal=3000` 可缩短赛程便于测试。

### 🗣️ 灵矽语音助手（可选）

接入七牛 [灵矽 AI 平台](https://linx.qiniu.com/docs)，网页把自己当成一台设备，游戏操作注册成端侧 MCP 工具，
在**主页 / 结算界面**直接说话控制菜单：「开始游戏」「再来一局」「灵敏度调低点」「把音效关了」「帮我上榜，花名小王」。

- 只在主页 / 结算界面收音，对局中不上传（跳跃仍走本地音量判断，语音识别往返太慢）
- 首次接入：开始界面点「🗣️ 连接灵矽语音助手」→ 页面显示 6 位激活码 → 在
  [灵矽智控台](https://xrobo.qiniu.com/) 智能体的「设备管理」里新增设备、填激活码 → 页面自动连上。
  没出激活码但回答的不是你的智能体时，用状态栏里的设备 ID（MAC）在「设备管理 → 批量导入」绑定后重连
- 智能体需要开启支持工具调用的意图识别（Function Call），才会调用游戏工具
- 设备身份存在浏览器 localStorage（`linx.deviceId` / `linx.clientId`），换浏览器算一台新设备
- 推荐 Chrome / Edge；协议细节见 [linx.js](linx.js) 顶部注释

## 运行

需要 Chrome / Edge（Safari 也可）。麦克风权限要求 `localhost` 或 HTTPS，所以本机起个服务：

```bash
bash start.sh          # 起本地服务(8080)并自动打开浏览器
# 或
python3 -m http.server 8080   # 然后访问 http://localhost:8080
```

## 现场部署清单（重要）

1. **提前授权麦克风**：演示机提前用 Chrome 打开一次、允许麦克风，之后不再弹窗（弹窗被忽略时游戏会在 8 秒后提示）。
2. **防回授**：大屏音箱别正对麦克风、拉开距离。代码已开浏览器回声消除，但物理隔离最稳。
3. **嘈杂环境**：每轮开局都有静默校准；观众欢呼声太大误触发时，把开始界面的「灵敏度」调低。
4. **投屏**：`F` 进全屏再投，1280×720 逻辑分辨率，大字号高对比，后排也看得清。
5. 想 WAN/手机访问？`getUserMedia` 需要 HTTPS，用内网穿透或 GitHub Pages。

## 调参

- 手感参数集中在 [game.js](game.js) 顶部常量区：自动跑速 `AUTO_V`、跳跃力度 `JUMP_V_MIN/MAX`、重力、赛程 `GOAL_DIST`（默认 12000px = 1000 行代码）。
- 音量门槛在 [audio.js](audio.js) 的 `Tjump`（默认 0.17，随校准噪音底自适应），开始界面的灵敏度滑杆实时缩放。

## 可行性评估（为什么做它 & 为什么能成）

- **技术**：只用 Web Audio 的 `getUserMedia + AnalyserNode` 读音量 RMS，不做语音识别，纯前端即可，
  Chrome/Edge/Safari 全支持。1.5 天估算偏保守：核心玩法原型 1 天内可完成，剩 0.5 天打磨文案/音效/调参。
- **现场效果**：「喊叫游戏 + 大屏围观 + 排行榜」是八分音符酱验证过的传播模型，天然排队。
- **主要风险与对策**：
  - 麦克风权限弹窗 → 演示机提前授权；弹窗被忽略时 8 秒超时提示，空格模式可兜底；
  - 环境噪音/欢呼误触发 → 开局校准 + 灵敏度滑杆 + 阈值随噪音底自适应；
  - 音箱回授 → 回声消除 + 物理隔离；
  - 多人共用排行榜（手机扫码提交成绩）才需要后端 → 二期再做，单机 localStorage 够用。

## 已验证（浏览器自动化实测）

- `?demo` 自动模式：连续多局无伤通关（声控跳跃 / 纸飞机闭嘴 / 深坑起跳全链路真实走通）
- 空格蓄力：200ms 蓄力腾空 192px、500ms 蓄力 221px（与物理公式推算值 194/224 吻合，按得越久跳得越高）
- 无输入必死：不喊就撞上第一个障碍（这游戏没有白嫖）
- 死亡流程：💀 死因文案 + 复活小技巧 → 填花名上排行榜 → Enter 重开 / Esc 回主页
- 麦克风降级：权限被拒有明确报错；权限弹窗无人理会时 8 秒超时提示
