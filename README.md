# 🐵 吗喽声控跑酷 —— 别让吗喽掉进 Bug

一个给团队活动 / 年会暖场用的**声控跑酷小游戏**：吗喽自动往前跑，你只负责一件事——**喊**。
看到障碍大喊一声让它跳过去，**喊得越响跳得越高越远**；持续嘶吼充满「发疯值」还能狂暴捶爆 Bug；
躲开 NullPointerException、404、P0 故障、需求变更（纸飞机）和技术债深坑，
沿途收集 ☕咖啡 🧋奶茶 加分，跑满 1000 行代码即可「成功上线」。

纯前端：Canvas + Web Audio，**零运行时依赖、无后端、无构建**。

## 玩法速览

| 情况 | 操作 / 结果 |
| --- | --- |
| 移动 | 吗喽自动奔跑（全程 300→380 渐进提速，终点前进入 🚀 冲刺段） |
| 🐛🚧💣 地面障碍 | **大喊起跳**：越响跳得越高越远（小声=小跳，满嗓门=大跳） |
| ✈️ 纸飞机（需求变更） | **闭嘴！** 它靠近时发疯值冻结（闭嘴区），起跳必死 |
| 🕳️ 技术债深坑 | 坑越宽越要喊得响，起跳别太早 |
| 😤 发疯值 | 持续大喊充电，满了触发 5 秒**发疯写码**：加速 + 写码双倍 + 一拳捶爆地面障碍（纸飞机/深坑依然致命） |
| ☕🧋 道具 | 咖啡小跳可得 +20 行，奶茶要满力跳 +50 行 |
| 📋 计分 | 里程 + 连躲奖励（躲过纸飞机双倍）+ 道具 + 捶爆奖励 |

- `F` 全屏 · `M` 音效/BGM 开关
- 开局流程：**开麦 → 安静 2 秒测噪音底 → 用最大声喊一嗓子（按你的嗓门校准起跳线）** → 3-2-1 开跑
- 死亡后输入花名上排行榜（本机 localStorage 前 10 名，附对应复活小技巧）

### ⌨️ 开发调试：空格 / 触摸模拟喊声

没有麦克风也能玩：**按住空格（或长按屏幕）蓄力，按得越久"嗓门"越大，松开喊出来**。
轻点≈小跳（~150px），按满 0.38s≈满力大跳（~207px）。`↑` 等效一次满喊。
开始界面点「⌨️ 空格调试模式（不开麦）」即可；开麦状态下同样可用，取较大值。

自动演示：`?demo`（内置 AI 自动玩，投屏暖场 attract mode）；`?goal=3000` 缩短赛程便于测试。

## 运行

Chrome / Edge / Safari。麦克风要求 `localhost` 或 HTTPS：

```bash
bash start.sh                        # 起本地服务(8080)并自动打开浏览器
# 或
python3 -m http.server 8080          # 访问 http://localhost:8080
```

- **在线版（HTTPS，手机可直接玩）**：<https://vjoy233.github.io/malou-voice-runner/>
- **断网兜底**：首次打开后 Service Worker 缓存全部资源，断网刷新照玩；也可用 `dist/malou-offline.html` 单文件版（U 盘即用）
- **摆摊模式**：手机浏览器"添加到主屏幕"，打开即全屏

## 冒烟测试

cd tests && npm install && npm test   # 10 项断言：demo 通关/蓄力力度/道具/发疯值/规则一致性
```

狂暴中纸飞机仍致命（规则一致性）、全程无 JS 错误。改手感参数后建议先跑一遍。

```
malou/
├── index.html            # 页面骨架与文案（PWA meta）
├── style.css             # 样式（深色高对比，投影友好）

│   ├── util.js           #   工具函数 + 画布上下文
│   ├── config.js         #   全部可调参数（手感/难度/计分/发疯值/道具）
│   ├── voice.js          #   麦克风：RMS 音量、噪音底校准、试喊校准、自适应阈值

│   ├── world.js          #   障碍/道具生成与难度曲线
│   ├── game.js           #   状态机、物理、计分、发疯值、输入（键盘/空格/触摸）
│   ├── render.js         #   全部 Canvas 绘制（含粒子/HUD）
│   ├── ui.js             #   DOM 界面、排行榜、麦克风流程
│   └── main.js           #   主循环、启动、SW 注册
├── sw.js                 # Service Worker（离线缓存）
├── manifest.webmanifest  # PWA 清单
├── icon.svg / icon-*.png # 图标
├── tools/build-offline.mjs   # 生成 dist/malou-offline.html 单文件离线版
├── tests/smoke.spec.mjs      # Playwright 冒烟测试
├── docs/TEST-CHECKLIST.md    # 真机测试清单（发布/活动前人工过一遍）
└── start.sh              # 一键启动

## 现场部署清单（重要）

1. **提前授权麦克风**：演示机提前用 Chrome 打开一次、允许麦克风（弹窗被忽略 8 秒后会提示）。
2. **每人开局自动校准**：安静底 + 试喊定起跳线，无需现场调参；观众太吵可把开始界面的「灵敏度」调低。
3. **防回授**：大屏音箱别正对麦克风；代码已开回声消除，物理隔离最稳。
4. **投屏**：`F` 全屏，1280×720 逻辑分辨率，后排看得清。
5. 真机验收项见 [docs/TEST-CHECKLIST.md](docs/TEST-CHECKLIST.md)（iOS 静音键、微信内置浏览器等已知限制也写在里面）。

## 调参

全部集中在 [js/config.js](js/config.js)：跑速曲线（`AUTO_V_START/END`、冲刺）、跳跃（`JUMP_V_MIN/MAX`、`CHARGE_FULL_T`）、
难度（`DIFF`）、计分（`SCORE`）、道具（`PICK`）、发疯值（`MAD`）。
音量阈值在 [js/voice.js](js/voice.js) 的 `Tjump`（试喊校准后自动适配，灵敏度滑杆实时缩放）。

## 已验证

- **自动化冒烟测试 10/10 通过**（Playwright，`tests/smoke.spec.mjs`），关键数值断言：
  - 空格蓄力 180ms 腾空 148px / 500ms 207px（功率沿蓄力期线性上升，按得越久跳得越高）
  - 触摸长按 = 满力跳；道具小跳/满跳分别可得；发疯值满 → 狂暴 → 捶爆障碍 +30 行
  - 规则一致性：狂暴不能免疫纸飞机（闭嘴区设计不被破坏）
- 修复过的代表性问题：喊声包络化（单帧脉冲导致发疯值永远充不满）、道具判定区间（一半概率站着白拿）
