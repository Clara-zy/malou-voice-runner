# 🐵 别让吗喽掉进 Bug

一个给团队活动 / 年会暖场用的**声控跑酷小游戏**：吗喽自动往前跑，你只负责一件事——**喊**。
看到障碍大喊一声让它跳过去，**喊得越响跳得越高越远**；空中拖长音能滑翔过宽坑；持续嘶吼充满「发疯值」还能狂暴捶爆 Bug。
一局就是一个工作日：从早高峰熬到凌晨上线，躲开 NullPointerException、404、P0 故障、需求变更（纸飞机）和技术债深坑，
☕咖啡回血发疯值、🧋奶茶给护盾、🍌香蕉攒够了摸鱼；最后还要过**产品经理**这一关，跑满 1000 行代码即可「成功上线」。

- 🎮 **在线试玩**（HTTPS，手机可直接玩）：<https://vjoy233.github.io/malou-voice-runner/>
- 🎬 **演示视频**：[演示视频.mov](%E6%BC%94%E7%A4%BA%E8%A7%86%E9%A2%91.mov)

纯前端：Canvas + Web Audio，**零运行时依赖、无后端、无构建**。

## 玩法速览

| 情况 | 操作 / 结果 |
| --- | --- |
| 移动 | 吗喽自动奔跑（全程 300→380 渐进提速，终点前进入 🚀 冲刺段） |
| 📅 工作日阶段 | 一局 = 一个工作日：🌅 早高峰 → ☕ 站会 → 📝 需求又变了 → 🌙 深夜加班 → 🚀 凌晨上线；天色/窗灯随阶段变，切换时弹横幅 |
| 🧩 套路段 | 按阶段解锁障碍组合：连环 Bug、高低交替、闭嘴后起跳、奶茶诱惑、连环坑（其余仍是散件） |
| 🐛🚧💣 地面障碍 | **大喊起跳**：起跳力度按「你的起跳线→满嗓门」的个人区间线性取值，喊声峰值越高跳得越高（~100px→254px）、前冲越远 |
| ✈️ 纸飞机（需求变更） | **闭嘴！** 迎面飞来时起跳必死；它在前方时发疯值冻结（闭嘴区，飞过头顶即解除） |
| 🕳️ 技术债深坑 | 坑越宽越要喊得响，起跳别太早；空中**持续喊**可滑翔（只在下落段减重力） |
| 🎙️ 长音滑翔 | 下落时音量过起跳线 → 重力约 45%，用来过宽坑；松口立即恢复 |
| 👔 Boss | 凌晨上线阶段产品经理拦路：软门挡住去路，甩快飞机、放 Bug 爬过来；发疯冲上去撞破 +100 行（冲锋时它会停手）；超时约 8 秒撤兵也可冲线 |
| 😤 发疯值 | 持续大喊充电（约 2 秒喊满），满了触发 5 秒**发疯写码**：加速 + 写码双倍 + 一拳捶爆地面障碍（纸飞机/深坑依然致命），结束后冷却 3 秒 |
| ☕🧋🍌 道具 | ☕+20 行并回充发疯值；🧋+50 行并获 1 层护盾（挡一次致死）；🍌+15 行，集 3 根触发 4 秒摸鱼自动跳 |
| 📋 计分 | 里程 + 连躲奖励（躲过纸飞机双倍）+ 道具 + 捶爆奖励；结算显示倒在哪个阶段 |

- `F` 全屏 · `M` 音效/BGM 开关
- 开局流程：**开麦 → 安静 2 秒测噪音底 → 用最大声喊一嗓子（按你的嗓门校准起跳线）** → 3-2-1 开跑
- 死亡后输入花名上排行榜（本机 localStorage 前 10 名，附对应复活小技巧）

### ⌨️ 开发调试：空格 / 触摸模拟喊声

对局中**按住空格（或长按屏幕）蓄力，按得越久"嗓门"越大，松开喊出来**，与麦克风取较大值。
轻点≈小跳（~120px），按满 0.38s≈满力大跳（~236px）。`↑` 等效一次满喊。
空中提前喊的落地缓冲跳会继承喊声力度，不丢档。

**麦克风路径的力度是怎么算的**：音量过起跳线后不立刻跳，先在 ≤120ms 的短窗内抓这口喊声的峰值
（还在爬升就延长窗口），按峰值在「起跳线→你校准出的满嗓门 90%」区间里线性取力度——
渐强式的喊也能得到应有的力度，不会锁死在最小跳。大声跳还附带随力度衰减的前冲加速，
"越喊跳得越远"在距离上同样明显。

自动演示：`?demo`（内置 AI 自动玩，投屏暖场 attract mode）；`?goal=3000` 缩短赛程便于测试。

### 🗣️ 灵矽语音助手（可选）

接入七牛 [灵矽 AI 平台](https://linx.qiniu.com/docs)，网页把自己当成一台设备，游戏操作注册成端侧 MCP 工具，
在**主页 / 结算界面**直接说话控制菜单：「开始游戏」「再来一局」「灵敏度调低点」「把音效关了」「帮我上榜，花名小王」。

- 只在主页 / 结算界面收音，对局中不上传（跳跃仍走本地音量判断，语音识别往返太慢）
- 打开页面默认自动连接（`?nolinx` 不连）；连接状态、断开/重连在主页右上角 ⚙️ 设置里（灵敏度也在这里）。
  浏览器要求用户手势后才放行音频，开场白会在首次点击/按键时念
- 首次接入：自动连接时设置面板会弹出 6 位激活码（齿轮亮红点）→ 在
  [灵矽智控台](https://xrobo.qiniu.com/) 智能体的「设备管理」里新增设备、填激活码 → 页面自动连上。
  没出激活码但回答的不是你的智能体时，用状态栏里的设备 ID（MAC）在「设备管理 → 批量导入」绑定后重连
- 智能体需要开启支持工具调用的意图识别（Function Call），才会调用游戏工具
- 设备身份存在浏览器 localStorage（`linx.deviceId` / `linx.clientId`），换浏览器算一台新设备
- 推荐 Chrome / Edge；协议细节见 [linx.js](linx.js) 顶部注释

## 运行

Chrome / Edge / Safari。麦克风要求 `localhost` 或 HTTPS：

```bash
bash start.sh                        # 起本地服务(8080)并自动打开浏览器
# 或
python3 -m http.server 8080          # 访问 http://localhost:8080
```

- **在线版**：<https://vjoy233.github.io/malou-voice-runner/>
- **断网兜底**：首次打开后 Service Worker 缓存全部资源，断网刷新照玩；也可用 `dist/malou-offline.html` 单文件版（U 盘即用）
- **摆摊模式**：手机浏览器"添加到主屏幕"，打开即全屏

## 现场部署清单（重要）

1. **提前授权麦克风**：演示机提前用 Chrome 打开一次、允许麦克风（弹窗被忽略 8 秒后会提示）。
2. **每人开局自动校准**：安静底 + 试喊定起跳线，无需现场调参；观众太吵可在主页右上角 ⚙️ 设置里把「喊声灵敏度」调低。
3. **防回授**：大屏音箱别正对麦克风；代码已开回声消除，物理隔离最稳。
4. **投屏**：`F` 全屏，1280×720 逻辑分辨率，后排看得清。
5. 真机验收项见 [docs/TEST-CHECKLIST.md](docs/TEST-CHECKLIST.md)（iOS 静音键、微信内置浏览器等已知限制也写在里面）。

## 调参

全部集中在 [js/config.js](js/config.js)：跑速曲线（`AUTO_V_START/END`、冲刺）、跳跃（`JUMP_V_MIN/MAX`、`CHARGE_FULL_T`）、
难度（`DIFF`）、阶段（`STAGES`）、计分（`SCORE`）、道具（`PICK`）、发疯值（`MAD`）、滑翔（`GLIDE`）、Boss（`BOSS`）。
套路段在 [js/world.js](js/world.js) 的 `PATTERNS`；音量阈值在 [js/voice.js](js/voice.js) 的 `Tjump`（试喊校准后自动适配，灵敏度滑杆实时缩放）。
